Configuración inicial (una vez por dispositivo):
1. Crea un repositorio privado en GitHub, ej: finhome-data
2. Ve a Settings → Developer settings → Personal access tokens → Fine-grained
3. Genera token con permiso Contents: Read & Write en ese repo
4. Tanto tú como tu mujer generáis vuestro propio token apuntando al mismo repo
